Bulk Import Universities

Add, update, or delete many universities and their program requirements at once by uploading a CSV file — no need to enter them one by one in the admin panel.

1. Get the template

Download a starter CSV with the correct column headers and two example rows (one add, one delete). Open it in Excel, Google Sheets, or Numbers — fill in a row per program, then export/save as CSV again before uploading.

⬇ Download CSV Template

2. Understand the columns

  • university_name — required. Rows with the same name update the same university.
  • major — one row per program/major offered. A university needs at least one program to show up in student matches. Leave blank if you only want to set up the university without a program yet.
  • action — leave blank to add/update. Set to delete to remove: a row with major filled in deletes just that program; a row with major blank deletes the whole university (and all its programs).
  • teaching_style, career_focus, social_scene — write a real sentence containing descriptive words (e.g. "hands-on labs, project-based learning"), not a single tag. The matching algorithm searches this text for keywords to score fit against student answers.
  • campus_type — one of: large_urban, medium, small_liberal, online.
  • numerus_fixus — yes or no.
  • Any column left blank on an update to an existing university/program keeps the current value — it won't be wiped out.
